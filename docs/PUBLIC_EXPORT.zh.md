# 公开快照范围

## 包含

- 模型、训练、采样、打包、清洗、评测、基准和回归源码。
- JSON Schema、评分提示词、脱敏配置与部署模板。
- 新编写的使用说明和聚合验收结论。

## 不包含

- 原仓库历史、个人标注记录、内部审批或评审账号绑定。
- 私有配置、真实姓名/邮箱、个人目录、实际 SSH 别名与服务器地址。
- 环境文件、API/SSH 密钥、认证 Cookie、私有配置档。
- 数据正文、模型权重、优化器状态、缓存、日志、TensorBoard、原始评测生成和回执。

`/srv/small-agent`、`/opt/small-agent/venvs`、`/home/user`、`/path/to/...` 是示例路径；`CPU_NODE`、`GPU_NODE` 是占位别名；RFC 5737 地址是文档用网段。配置必须由部署者重新核对，原内部配置授权不随源码转移。

发布前对文件名、内容和首次提交做敏感信息检查，并对 Python/JSON 做语法校验。测试夹具里的统计计数不是个人电话号码；占位服务实例名中的 `@` 不是邮箱。原始匹配内容及私有导出台账不随仓库发布。

公开快照不是原服务器运行目录，也不是原 checkpoint 的原位恢复源码；脱敏使源树身份不同，不应强行用于旧运行目录的审计式 `--resume`。
